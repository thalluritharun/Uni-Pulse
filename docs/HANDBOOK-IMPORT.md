## Added now

- `js/handbooks.js` maps all six subjects to these original reader links. The UI explicitly says that downloads are restricted; it does not claim a local PDF is available.
- Faculty demo mode is isolated from normal profiles and uploaded files.
- Chapter quiz support is available and uses the existing PEA 101 question bank without changing it.
- Existing lessons, source collections, source PDFs/images, and question-bank text remain unchanged.

## Still needs source access

Missing subject units, chapter summaries, new practice question banks, and their grand tests cannot be completed accurately until the PDFs can be read in full. The original files also cannot be bundled for download yet. Grand tests retain their existing readiness requirements and stay unavailable for incomplete subjects.

To resume, the owner can enable viewer downloads, provide the original PDFs directly, or make the files available through an owner/editor Google Drive connection. The user permits summaries of newly imported material, while existing lesson content must be preserved.
